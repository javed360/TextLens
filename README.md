# TextLens — বিল্ড ও ব্যবহার

## ১. বিল্ড (দুই উপায়)

**ক) Android Studio (কম্পিউটারে)**
1. Android Studio (Koala বা নতুন) খুলে `File → Open` দিয়ে এই `TextLens` ফোল্ডার খুলুন।
2. Gradle sync শেষ হলে `Build → Build APK(s)`। APK থাকবে `app/build/outputs/apk/debug/app-debug.apk`।
3. (ঐচ্ছিক) `app/src/main/assets/tessdata/` ফোল্ডারে `ben.traineddata`, `ara.traineddata`, `eng.traineddata` রাখলে অফলাইন প্রথম রান চলবে
   (Bengali/Arabic: https://github.com/tesseract-ocr/tessdata_best, English: https://github.com/tesseract-ocr/tessdata_fast)।
   না রাখলে APK ছোট হবে এবং অ্যাপ প্রথম OCR-এর সময় নিজেই একবার নামিয়ে নেবে।

**খ) কম্পিউটার ছাড়া — GitHub Actions (মোবাইল থেকে)**
1. GitHub-এ নতুন repository খুলে এই ফোল্ডারের সব ফাইল আপলোড করুন। তারপর `.github/workflows/build.yml` নামে নতুন ফাইল বানিয়ে চ্যাটে দেওয়া build.yml-এর লেখা বসান।
2. `Actions → Build APK → Run workflow`। `ocr_data` অপশন:
   - `mixed` (ডিফল্ট) — বাংলা+আরবি ভালো মডেল, ইংরেজি ছোট মডেল, APK-র ভেতরে;
   - `fast` — তিনটাই ছোট মডেল (সবচেয়ে ছোট বান্ডিল, একটু কম নির্ভুল);
   - `none` — কিছুই ঢোকে না, APK সবচেয়ে ছোট; অ্যাপ প্রথমবার নিজে নামিয়ে নেয়।
   শেষ হলে Artifacts থেকে `TextLens-debug-apk` নামান।
3. APK ইনস্টলের সময় "Unknown sources" অনুমতি দিতে হবে।

**APK সাইজ:** শুধু ARM (arm64-v8a, armeabi-v7a) রাখা হয়েছে, native লাইব্রেরি কমপ্রেসড, শুধু en/bn/ar রিসোর্স। তবু debug APK-তে Tesseract + ML Kit + PDFBox থাকায় বড় থাকে; আরও ছোট করতে `ocr_data = none`, অথবা পরে release build (R8) দেখা যায়।

## ২. প্রথমবার চালানো
1. অ্যাপের নিচের বারে **Permissions** ট্যাবে গিয়ে স্ক্রিনশট সার্ভিস (Accessibility), Overlay, Camera, Notification ও Battery চালু করুন।
   (Accessibility চালু থাকলে কলম/বক্স চাপলে স্ক্রিন-রেকর্ডের ডায়ালগ আসে না। বন্ধ থাকলে প্রতিবার ডায়ালগ আসবে।)
2. Quick Settings (স্ট্যাটাস বার দুইবার টানুন) → Edit → **TextLens বাবল** টাইল যোগ করুন।
3. টাইলে চাপুন → গোল বাবল আসবে। বাবলে চাপুন → কলম / বক্স / ক্যামেরা।
4. কলম দিয়ে লেখার উপর টানলে আঁকা শেষে নিজে বক্স হয়ে যাবে; বক্সের কোণা/কিনারা টেনে বড়-ছোট করা যায়, ভেতরে ধরে সরানো যায়। "লেখা নিন" চাপলে ফলাফল প্যানেল আসে (সবকিছু আপনার চলতি অ্যাপের উপরেই)।
5. বাবল সরাতে: টেনে নিচের লাল X-এ ছাড়ুন, অথবা টাইলে আবার চাপুন।

## ৩. সীমাবদ্ধতা
- অনুবাদের ভাষা-মডেল (প্রতিটি ~৩০MB) প্রথমবার ইন্টারনেটে নামে; এরপর অফলাইন।
- Android-এর নিয়মে বাবল চালু থাকলে নোটিফিকেশন প্যানেলে একটা নীরব সার্ভিস লাইন থাকবেই (স্ট্যাটাস বারে আইকন আসে না)।
- OCR: ছাপা লেখায় ভালো; হরকতসহ আরবি বা ঝাপসা/হাতের লেখায় ভুল হতে পারে — ফলাফল স্ক্রিনে ঠিক করে নিতে পারবেন।
- এই কোড এখনো কোনো ফোনে চালিয়ে পরীক্ষা করা হয়নি; প্রথম বিল্ডে ছোটখাটো error আসতে পারে — error টেক্সট পাঠালে ঠিক করে দেব।
